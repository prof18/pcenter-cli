# pcenter-cli (`pcenter`)

A Go CLI for the Microsoft Store (Partner Center): publish MSIX releases, manage listings/screenshots/release notes from local files, fetch reviews, and manage rollouts and submissions. Built for FeedFlow but app-agnostic.

**Status:** M1 is complete. The read-only command set is implemented and verified against both the fake Partner Center server and the live Store API. Submission mutations, publishing, and listing management remain milestone work tracked in the plan.

Start here: [plan/INDEX.md](plan/INDEX.md). Track progress in [plan/TODO.md](plan/TODO.md).
