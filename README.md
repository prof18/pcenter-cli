# pcenter-cli (`pcenter`)

A Go CLI for the Microsoft Store (Partner Center): publish MSIX releases, manage listings/screenshots/release notes from local files, fetch reviews, and manage rollouts and submissions. Built for FeedFlow but app-agnostic.

**Status: planning — implementation not started.**
